# Registro de Prompts Iniciales y Spec Kit

## 1. Prompt Inicial de Planeación (Backend POO)
> "Necesito desarrollar un sistema en Python utilizando Programación Orientada a Objetos (POO) que permita modelar y estructurar un mapa de conocimiento académico mediante nodos interconectados y gestión de prerrequisitos."

## 2. Prompt de Refactorización a Arquitectura por Capas
> "Por favor, reestructura el código actual del proyecto separándolo en una arquitectura limpia por capas: Repositorios para los datos, Servicios para la lógica de negocio y Controladores para la interacción."

## 3. Especificación del Spec Kit
* **Lenguaje:** Python 3.x
* **Paradigma:** POO (Programación Orientada a Objetos)
* **Control de versiones:** Git y GitHub (con uso de ramas `feature/` y `main`).
